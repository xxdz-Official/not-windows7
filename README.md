# not-windows7
这并非Windows7，但它可以...跳出你的浏览器(?) 无技术力纯整活....

### 哔哩Toy已上架本网页，欢迎访问喵！

https://www.bilibili.com/toy/not-windows7

建议下载本地端以获得“从网页飞入电脑”的效果~
（需要python环境）

### 本地端の要求：

Python 版本：建议 3.8 ~ 3.11

操作系统：仅 Windows（依赖 win32 API 与 .ico 资源）

安装：pip install -r requirements.txt

运行：python main.py（前端 index.html 需另开浏览器/本地服务器访问）

资源文件：img/ 目录（含 imageres_98.ico、Dengl.ttf 等）必须与脚本同目录层级
